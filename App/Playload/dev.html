The whole API

cls(col) clear the text screen

put(cx, cy, str, col1, col2) text, 20 x 18 cells

spr(x, y, chr, col) sprite, this frame only

btn(i) btnp(i) 0-5: up down left right A B

play(ch, score) 3 channels, MML-like

scr[cy][cx] .chr .col the cells

pcg[chr] .pat .col redefine a character

function tick() {} runs 60 times a second

Colors 0-7: black, purple, gray, red, blue, green, yellow, white.
